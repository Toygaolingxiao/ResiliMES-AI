2. 评审原文中已有实现的事项（归档版本 `c9d71dd` 时已实现，勿重复立项）：

3. 评审原文与设计稿互相不点名：评审 §5 只写“完整设计稿见同一对话中的设计页”，设计稿内未提及评审文件名。两者以同日期前缀关联。
